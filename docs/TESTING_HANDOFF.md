# Antigravity / Local Verification Handoff — shanXAI V2

## Setup

```powershell
git clone https://github.com/shanmukhdatta/shanmukhdatta.github.io.git
cd shanmukhdatta.github.io
git fetch origin
git switch redesign/shanxai-portfolio-v2
npm install
npm run check:content
npm run typecheck
npm run build
npm run dev
```

Open `http://localhost:3000`. No external API key is needed to explore the current website.
